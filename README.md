# db-project-autoschool

# Информационная система автошколы (PostgreSQL)

Учебный проект по курсу «Базы данных». Система предназначена для автоматизации учебного процесса автошколы: ведение курсантов, договоров и платежей, расписание практических вождений, контроль состояния учебного автопарка и фиксация результатов экзаменов.

## Структура репозитория
* `./schemas` — Концептуальная, логическая и физическая схемы базы данных.
* `./data` — Наборы синтетических данных (CSV-файлы) для наполнения таблиц.
* `./base_part` — SQL-скрипты создания БД, DDL-ограничения, 15 аналитических SELECT-запросов.
* `./advanced_part` — Индексы, представления (Views), хранимые процедуры/функции, триггеры, версионность (SCD).
